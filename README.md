# Search · 无信息流的搜索直达启动器

Search 是一个极简的 Android 启动器：首页只有一个输入框和 4×3 应用图标，输入关键词直接落到目标 App 的**搜索结果页**，跳过开屏广告、首页推荐和短视频信息流。

本项目是 [oldjie/yisou](https://github.com/oldjie/yisou)（一搜）的**修改版（衍生作品）**，在此基础上做了界面、字体、图标与体积方面的改造。原作的搜索直达思路、平台适配方案与微信坐标校准方案是本项目的基础，在此致谢。

- 包名：`org.nofeed.android`
- 版本：`1.2.0`（versionCode 21）
- 最低系统：Android 8.0（API 26），编译与目标 API 35
- 许可：AGPL-3.0-only

## 功能

### 搜索直达

- 16 个平台适配：抖音、知乎、小红书、哔哩哔哩、淘宝、闲鱼、拼多多、大众点评、豆瓣、美团、微信、高德地图、网易云音乐、酷安、雪球、微信读书。
- 优先用平台的 deeplink 直接跳搜索结果页，未安装时按需回落到网页搜索地址；链接模板集中在 `SearchTarget`，新增平台只需加一行枚举。
- 输入框支持搜索历史、历史单条删除与清空，历史只存本机。
- 微信没有公开的搜索 deeplink，沿用原作的坐标校准 + 辅助功能（无障碍服务）点击方案：先手工校准搜索入口位置，再由服务模拟点击与粘贴关键词；该服务默认关闭，需用户主动开启。

### 首页

- 底部输入框 + 上方 4×3 图标网格，图标由系统返回的应用图标实时取用，无需内置图标资源。
- 网格横向左右滑动翻页，底部页码圆点指示当前位置。
- 图标可自行增删与排序，保存的选择在本机持久化。

### 1.2.0 的改造点

| 改造 | 说明 |
| --- | --- |
| 图标统一圆角 | 绘制后先扫描 alpha 得到实际内容边界盒，等比放大铺满图块，再用边长 0.22 的圆角矩形遮罩裁剪。自适应图标（内容约占安全区 83%）与铺满型 legacy 图标由此获得同一致的圆角轮廓，且关键内容不被裁掉 |
| 跟随系统字体 | 移除内置的中文字体（Noto Serif SC，约 11.6 MB），全量改为系统无衬线字体，界面字体随系统变化 |
| 体积精简 | 上述字体移除后，APK 由约 9.6 MB 降至约 0.23 MB |
| 键盘不遮挡 | 输入法弹出时按剩余可视高度重算网格行高，三行图标不会被键盘盖住，最后一行始终可见 |

### 其他

- 桌面小组件：4×3 应用页小组件与搜索输入框小组件。
- 设置页：外观（浅色/深色）、图标选择、微信校准、搜索次数统计、许可与源码入口。
- 无网络权限、无广告、无统计 SDK、无需账号；除微信辅助功能外不申请敏感权限。

## 安装

从 [Releases](https://github.com/cedargpt/Search/releases) 下载 `Search-1.2.0.apk`，用系统文件管理器打开安装（系统可能要求先允许该文件管理器安装应用）。

## 构建

```bash
./gradlew :app:assembleDebug     # 产物在 app/build/outputs/apk/debug/
./gradlew :app:assembleRelease   # 未配置签名时使用 debug 签名
```

需要 JDK 17 与 Android SDK 35，`local.properties` 指向本机 SDK 路径（已被 .gitignore 忽略）。
